## Как пользоваться

- **Откройте нужную категорию** или воспользуйтесь поиском GitHub по файлам.
- **Проверьте первоисточник**: лицензию, историю обновлений, документацию, поддержку и условия эксплуатации.
- **Предложите проект или исправление** через [Pull Request](../../pulls) либо [Issue](../../issues/new/choose).
- **Не воспринимайте запись как техническую гарантию.** Наличие ссылки не доказывает, что проект протестирован или безопасен.

## Принципы

Предпочитаем официальные репозитории, конкретные описания и полезные инструменты, а не рекламу. Коммерческие решения допустимы, но бесплатность и открытость исходников нельзя утверждать без проверки. Партнёрские и отслеживающие ссылки не принимаем. Не переносим сюда чужие README, книги, изображения и исходный код без разрешения.
