# Discovery sources

These third-party directories are useful for finding candidates for the catalog. Their descriptions and lists should **not** be copied wholesale; review and link each primary resource separately.

- [Awesome](https://github.com/sindresorhus/awesome) — many topical Awesome lists.
- [Awesome Self-Hosted](https://github.com/awesome-selfhosted/awesome-selfhosted) — software suitable for hosting on private infrastructure.
- [Free for Dev](https://github.com/ripienaar/free-for-dev) — free tiers for developers; terms change.
- [Public APIs](https://github.com/public-apis/public-apis) — publicly listed APIs.
- [Awesome Design System Components](https://github.com/6igtree/awesome-design-system-components) — design systems with publicly available component code.
- [Awesome Open Source Boilerplates](https://github.com/EinGuterWaran/awesome-opensource-boilerplates) — software starter templates.
- [Project-Based Learning](https://github.com/practical-tutorials/project-based-learning) — project-oriented education.
- [Build Your Own X](https://github.com/codecrafters-io/build-your-own-x) — build foundational software yourself.
- [Awesome MCP Servers](https://github.com/punkpeye/awesome-mcp-servers) — MCP server directory.
- [Awesome Database](https://github.com/0xMalaz/awesome-database) — database ecosystem references.

Upstream repositories retain their own licenses and editorial terms. Inclusion in this file is attribution as a discovery source, not reproduction or endorsement.
