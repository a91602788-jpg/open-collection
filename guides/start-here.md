# С чего начать / Start here

[Каталог / Catalog](../README.md) · [Как выбирать / How to choose](choosing-a-project.md)

Выберите задачу. Это варианты для изучения, а не готовый совместимый стек: версии, лицензии, сервисы и требования к хостингу оцениваются вместе перед внедрением.

Choose a task. These are starting points to investigate, not a prevalidated compatible stack. Check versions, terms, external services and hosting requirements together before adoption.

| Задача / Task | Отправные точки / Starting points | Что выяснить / Check first |
| --- | --- | --- |
| SaaS на React / React SaaS | [Open SaaS](https://github.com/wasp-lang/open-saas), [Next.js SaaS Starter](https://github.com/nextjs/saas-starter) | Billing provider, organizations, roles, migrations. |
| Python backend + UI | [Full Stack FastAPI](https://github.com/fastapi/full-stack-fastapi-template), [Cookiecutter Django](https://github.com/cookiecutter/cookiecutter-django) | Deployment configuration, authentication, background tasks. |
| Интерфейс / UI | [shadcn/ui](https://github.com/shadcn-ui/ui), [Mantine](https://github.com/mantinedev/mantine), [Lucide](https://github.com/lucide-icons/lucide) | Accessibility, framework support, customization model. |
| Мобильное приложение / Mobile app | [Expo](https://github.com/expo/expo), [Flutter](https://github.com/flutter/flutter) | Native integrations, release workflow, platform requirements. |
| AI и документы / AI with documents | [RAGFlow](https://github.com/infiniflow/ragflow), [LlamaIndex](https://github.com/run-llama/llama_index), [Ollama](https://github.com/ollama/ollama) | Data flow, model license, memory/GPU needs and API expenses. |
| MCP-интеграции / MCP integrations | [Reference servers](https://github.com/modelcontextprotocol/servers), [Python SDK](https://github.com/modelcontextprotocol/python-sdk) | Tool permissions, credentials, trust boundaries. |
| Интернет-магазин / Store | [Medusa](https://github.com/medusajs/medusa), [Saleor](https://github.com/saleor/saleor) | Storefront, payment and shipping integrations, refunds and stock. |
| CRM | [Twenty](https://github.com/twentyhq/twenty), [EspoCRM](https://github.com/espocrm/espocrm) | Roles, import/export, custom fields and integration limits. |
| ERP | [ERPNext](https://github.com/frappe/erpnext), [Odoo](https://github.com/odoo/odoo), [Dolibarr](https://github.com/Dolibarr/dolibarr) | Modules, localization, accounting requirements, upgrade path. |
| Личный бюджет / Personal budget | [Actual](https://github.com/actualbudget/actual), [Firefly III](https://github.com/firefly-iii/firefly-iii) | Import formats, currency support, backups and access. |
| Рецепты / Recipes | [Mealie](https://github.com/mealie-recipes/mealie), [Tandoor](https://github.com/TandoorRecipes/recipes) | Imports, household users and backup restoration. |
| Бронирование / Booking | [Cal.com source](https://github.com/calcom/cal.com) | Product scope and license: appointment scheduling does not implement hotel inventory. |
| Свой сервер / Own server | [Coolify](https://github.com/coollabsio/coolify), [Dokploy](https://github.com/Dokploy/dokploy), [Uptime Kuma](https://github.com/louislam/uptime-kuma), [Restic](https://github.com/restic/restic) | Server resources, isolation, updates and tested restore procedures. |
| Практика для новичка / Beginner practice | [Projects](https://github.com/karan/Projects), [App Ideas](https://github.com/florinpop17/app-ideas), [Awesome for Beginners](https://github.com/MunGell/awesome-for-beginners) | Ideas and contribution tasks are not finished applications. |
| Дизайн-ресурсы / Design resources | [Design Resources for Developers](https://github.com/bradtraversy/design-resources-for-developers), [Penpot](https://github.com/penpot/penpot) | Check each asset’s own license, attribution and redistribution terms. |
