**От готовой основы приложения до собственной инфраструктуры.**

Публичный каталог GitHub-проектов: шаблоны SaaS, компоненты, AI, CRM, ERP, дизайн, инструменты и учебные материалы. Без отдельного сайта.

**1,307 уникальных репозиториев · 63 направления · снимок метаданных 2026-10-27**

Начните с [подборки по задачам](guides/start-here.md), откройте нужный раздел ниже или скачайте [JSON-каталог](data/catalog.json). В каждом разделе можно искать через `Ctrl+F` / `⌘F`.

В обновлении v0.2 добавлены 120 записей с собственными описаниями RU/EN и новые подкатегории. [Изменения схемы данных](data/SCHEMA.md).

[Новое направление качества](37-design-quality-and-engineering-standards/README.md) включает 38 ресурсов с собственными описаниями RU/EN. [Первая партия из очереди](research/review-batches/2026-10-27-batch-01.json) предлагает 149 записей с описаниями RU/EN. В активной исследовательской очереди остаётся 1 879 кандидатов; они не входят в основной счётчик.

## Для AI-ассистентов

Начните с [llms.txt](llms.txt) или [компактного JSON-индекса](ai/index.json), затем читайте только нужный раздел. [Карта репозитория](SITEMAP.md) объясняет, какие файлы открывать по задаче. Размеры и SHA-256 помогают повторно использовать неизменные данные, если агент поддерживает кэширование.

## Что здесь проверено

В каждой записи есть ссылка на автора, описание, основной язык, распознанная GitHub лицензия и дата push. `metadata-checked` подтверждает существование публичного репозитория и получение этих сведений на дату снимка. Он **не означает запуск, аудит безопасности или проверку коммерческой лицензии**.

Готовые основы обозначены `starter`, подборки — `collection`, учебные материалы — `learning`, спецификации и наборы данных — `reference`; остальные программные проекты — `software`. Поле `resource_type` уточняет класс новых ресурсов. В индекс включены и инструменты с нестандартными условиями, поэтому весь каталог не называется open source. `CHECK-LICENSE` требует ручной проверки.

Для части отправных точек написаны краткие резюме RU/EN. Остальные описания — сокращённые до 24 слов сведения авторов из GitHub, на языке оригинала. Полный стек, актуальные тарифы, доступность облака и самостоятельного размещения в массовом индексе не проверены. Дата push не доказывает активную поддержку.
