# Security policy

Open Collection hosts Markdown links and small validation scripts, **not** copies of the listed applications. Inclusion does not mean security review or endorsement.

## Reporting a problem

- **Listed third-party project:** report vulnerabilities to that project's maintainer using their security policy. This repository cannot patch or coordinate disclosure for upstream software.
- **Broken, suspicious or malicious link:** use the issue template with non-sensitive evidence, or contact the repository maintainer privately when the report contains sensitive information.
- **Possible repository/workflow vulnerability:** do not post exploits, tokens, secrets or personal data in a public issue. Use GitHub private vulnerability reporting if available for this repository, or reach out privately using a contact channel exposed by its owner.

We do not promise a particular response time. Contributions are reviewed with least-privilege permissions. Pull request checks never need access to deployment or organization secrets.
