# Roadmap

The following are **goals, not published counts or promises of delivery dates**.

| Stage | Focus | Target |
|---|---|---|
| Foundation | Taxonomy, editorial policy, link validation, examples in every category | 24 categories |
| Growth | Community contributions, cross-category discoverability, updates | 1,000 reviewed listings |
| Expansion | More topics, independent periodic review, better metadata | 10,000 listings |
| Long term | Large multilingual reference, accessible without a proprietary website | 25,000+ listings |

## Possible enhancements

- More granular topic files when categories become difficult to browse.
- Optional machine-readable source metadata generated from canonical Markdown entries.
- Licence/pricing/maintenance metadata **only when independently confirmed**.
- Scheduled dead-link reports that open pull requests rather than modifying main automatically.
- Community-maintained Russian translations of topic entries.

No standalone site, account system, hosted database or backend service is required for the catalog.
