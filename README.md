## How to use it

- **Explore** by category. Use GitHub's file search to find a project or technology.
- **Compare** upstream licenses, maintenance status, documentation and hosting requirements before adopting a resource.
- **Contribute** a missing project or fix a broken link by opening a [pull request](../../pulls) or using an [issue template](../../issues/new/choose).
- **Verify** directly with the original publisher. Links can change, and this repository does not continuously test the listed software.

## Selection principles

We prefer canonical upstream links, concise original descriptions and practical value over promotional claims. Paid products can appear when relevant; they must not be presented as free or open source without evidence. No affiliate or tracking links. No copied third-party README bodies or unauthorized media. See [editorial policy](EDITORIAL_POLICY.md).

## Languages and scope

The navigation and project policies are available in English and Russian. The first category entries use concise English descriptions to avoid two unsynchronized copies; translations are welcome through pull requests. This repository is a **curated index, not a package mirror**. Nothing here requires deploying a website or service.
